# Project Rules & Customizations

## GitHub Push & Synchronization Rule
- **Always push all changes to GitHub**: Whenever any code, HTML, CSS, JavaScript, or asset changes are made in this repository, automatically stage (`git add .`), commit with a clear message (`git commit -m "..."`), and push (`git push origin main`) to the remote GitHub repository.
- Ensure the live repository and preview site are kept 100% updated at all times.
